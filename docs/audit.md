## 테스트 및 한계
- `npm test`: 6/6 통과. 순수 상태 전이만 검증하며 DOM이나 Chrome API를 검증하지 않습니다.
- `npm run build`: 성공, ZIP 생성. 설치 테스트는 수행하지 않았습니다.
- 이 환경에 Chrome/Chromium과 Playwright가 없어 브라우저 검증을 실행하지 않았습니다. 로그인된 실제 ChatGPT 및 Windows 알림 검증도 하지 않았습니다. 성능 수치는 측정하지 않았습니다.
- 완료 판정은 휴리스틱입니다. 도구 호출 중 일시적인 UI 전환, 빠른 응답, DOM 변경, 탐지 중단, 재접속에 취약합니다. 작업 ID는 탭별로 생성되며 동일 대화의 여러 탭을 중복 제거하지 않습니다. 오류 신호는 작업 시작 없이도 알릴 수 있습니다.
- Service Worker 상태 저장과 알림 사이에 크래시가 발생하면 알림이 누락될 수 있습니다. 페이지의 기존 오류 알림을 새 오류로 오인할 수 있습니다. 활성화 순간에 읽음 처리되므로 이미 보고 있던 탭에서 발생한 완료는 미확인으로 남을 수 있습니다.
- 메타데이터는 탭 ID 기반으로 저장되며 장기 프로젝트 설정/이력이 아닙니다. 브라우저 재시작 후 탭 ID 재사용과 상태 복원은 검증되지 않았습니다.
- 다른 AI 서비스 어댑터는 구현되지 않았습니다. 실제 사용량/토큰은 측정하거나 추정하지 않습니다.

## 보안 점검 범위
코드 검토상 외부 요청, 원격 코드, 쿠키/토큰 수집, 대화 본문 저장은 없습니다. 대화 제목과 경로는 로컬 저장되며, 알림에는 설정에 따라 제목이 노출될 수 있습니다. DOM 신호는 ChatGPT의 화면 변경에 종속되며 제3자 독립 보안 감사는 수행되지 않았습니다.
