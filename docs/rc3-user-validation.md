# RC3 실제 사용자 검증 기록

사용자가 Windows 11의 실제 Chrome에서 RC2에 대해 보고한 결과이며 이 환경에서 재현하거나 독립 확인한 결과가 아닙니다.

| 항목 | 사용자 보고 |
|---|---|
| 확장 설치 | PASS |
| 기존 ChatGPT 탭 자동 탐색 | PASS |
| 테스트 알림음 | PASS |
| Windows 알림 | 미확인 |
| 작업 시작 감지 | FAIL |
| 대시보드 | 확인 불가 지속 |
| 완료 감지·자동 알림 | 시작 감지 실패로 검증 불가 |

가능한 원인: 입력창/버튼 선택자와 UI 변경, 실제 주입 실패, SPA에서 sender.url 경로가 문서 생성 시점과 달라지는 경우 RC2의 엄격한 경로 검사 거부, 신규 대화 생성 시 `/` → `/c/…` 경로 초기화로 제출/진행 상태 유실. 이들은 코드 검토에 따른 가설이며 사용자의 실제 DOM이나 진단 데이터는 아직 확보하지 않았으므로 확정 원인으로 기록하지 않습니다.
