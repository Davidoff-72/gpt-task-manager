# 실제 사용자 보고 — RC3 파비콘

사용자는 Windows 11 / 실제 Chrome 환경에서 RC3의 탭 파비콘 색상 변경이 작동하지 않는다고 보고했습니다. 설치 여부, 설정값, CSP 오류, 사용된 Chrome 버전 및 재현 화면에 관한 추가 증거는 제공되지 않았으며 이 환경에서 독립 재현하지 않았습니다. 기존 RC2/RC3 상태 감지 및 알림 테스트 기록은 별도로 유지합니다.

초기 코드 검토상 기존 사이트 소유 icon 링크를 삭제하지 않고 끝에 SVG data URL 링크를 추가합니다. 사이트 아이콘과 브라우저의 선택/캐시, CSP의 img-src, 업데이트 시점, BFCache 및 확장 비활성화 시 잔존 링크가 영향을 줄 수 있으나 실제 원인은 확정되지 않았습니다. DOM 링크 존재는 Chrome 탭 표시 성공을 증명하지 않습니다.
