## 구현 및 알려진 결함

- 사용자 제출, Stop 표시, assistant DOM 변화, 마지막 응답의 복사 제어, composer, 도구 활동 및 안정화 후보를 결합. 30초 경과만으로 완료하지 않음. 그러나 ChatGPT에는 안정된 공개 DOM 계약이 없고 복사 제어가 중간 응답에 나타날 수 있어 **오탐을 배제하지 못함**. 도구 감지 실패나 10초 이상의 UI 공백도 위험. 반대로 빠른 작업, 버튼/언어 변경, 진입 전 실행, route 변경, 보이지 않는 제어는 누락될 수 있음.
- 페이지 재접속/새로고침/대화 전환에서 실행을 안전하게 무효화하며 복구하지 않음. 신규 대화 URL이 제출 직후 바뀌는 경우에도 알림이 누락될 수 있음. 작업 ID는 탭 단위이며 동일 대화의 여러 탭은 중복 알림 가능.
- 상태는 완료 전 저장되지만 저장 직후 알림 전 Worker가 종료되면 알림이 누락될 수 있음. 외부 알림 API의 정확히 한 번 전달을 보장하지 않음. 알림 및 소리 테스트는 요청만 확인하며 OS 표시와 재생을 보증하지 않음.
- 파비콘은 기본 꺼짐. 자체 링크만 추가/제거하지만 페이지 CSP와 Chrome 탭 렌더링, 사이트와의 상호작용은 미검증. 도구모음의 탭별 배지는 전역 미확인 수를 가릴 수 있음.
- `/c/` 대화의 프로젝트 이름은 로컬에 영구 저장되지만 그룹·색상·백업과 통계/이력은 없음. 브라우저 재시작 후 탭 ID 재사용·상태 복원은 미검증. 서비스에 따라 오류 메시지와 도구 표시를 놓칠 수 있음.
- 모의 DOM 시험은 개발자가 작성한 픽스처를 검증할 뿐, 독립적이거나 실제 서비스의 정확도를 검증하지 않음. 전체 기능, 영어 UI, 자동 보존 정책 등은 원장을 참조.

## 보안·개인정보 검토

정적 코드 검토상 확장은 외부 서버 요청, 토큰·쿠키 수집, 대화 본문 저장을 구현하지 않습니다. 오류·도구 여부를 위해 보이는 UI 텍스트를 메모리에서 검사하며 전송하지 않습니다. 제목, 경로, 프로젝트명 및 시각은 로컬에 보관되므로 민감할 수 있습니다. 옵트인 진단은 시각·이벤트·상태만 최대 100개 저장합니다. 사용자 문구는 `textContent`로 표시합니다. 송신자의 확장 ID, 최상위 프레임, 호스트, 경로를 검사하지만 Chrome 환경 및 독립 침투 테스트는 미실시. 기본 MV3 CSP를 사용하며 실제 사이트 CSP 호환성 미검증.

## Windows/실제 ChatGPT 수동 검증 체크리스트

이 항목은 사용자 실행용이며 실행 전에는 PASS가 아닙니다. 민감한 대화 제목과 내용은 캡처·공유하지 마세요.

1. [ ] Chrome에서 ZIP을 풀고 `chrome://extensions` → 개발자 모드 → 압축해제된 확장 로드. 오류 패널에서 Worker/manifest 오류가 없는지 확인.
2. [ ] ChatGPT 탭을 새로고침하고 대시보드 목록·사이드 패널·전체 화면을 확인. 설정의 알림 테스트 후 Windows 설정과 Chrome 권한, 실제 소리를 확인.
3. [ ] 이미 끝난 대화와 이미 생성 중이던 페이지를 열거나 새로고침했을 때 가짜 완료 알림이 없는지 확인.
4. [ ] 새 메시지를 제출해 작업 중 표시, 스트리밍과 최종 답변 후 완료 표시 및 알림 1회, 알림 클릭 시 올바른 창·탭 이동을 확인. 같은 탭에서 후속 질문과 재생성을 반복.
5. [ ] 장시간 추론, 웹 검색/도구 호출 및 중간 응답 사이에서 완료 알림이 나오지 않는지 확인. 10초 이상의 중간 공백도 시도하고 최종 답변을 직접 대조.
6. [ ] Stop 클릭, 오류, 사용량 제한, 네트워크 중단, 다른 대화 이동, 새로고침, 탭 폐기/복원에서 정상 완료로 잘못 알리지 않는지 확인.
7. [ ] 10/20/30개 탭과 여러 창에서 동시에 제출·완료, 중복 대화, 대시보드 동기화 및 성능을 확인. 메모리 절약, Chrome/Worker 재시작, 장시간 실행도 별도 확인.
8. [ ] 실험적 파비콘 설정을 켜고 사이트 고유 아이콘 업데이트와 상태 표시를 확인한 뒤 끄고 원본이 복원되는지 확인. 확장 비활성화 후에는 탭 새로고침.
9. [ ] 필요시 제목 없는 진단 로그를 켜고 재현 후 로그를 확인·삭제. 로그에는 시각이 남으므로 공유 전 검토.

위 항목과 문제 재현을 통해 오탐·누락을 수정하고, 실제 확장 E2E·Windows 검증·독립 보안 검토가 끝날 때까지 출시 승인은 보류합니다.
