# RC3 파비콘 수정 — 검증 및 사용자 재시험

## 사용자 보고 및 원인
사용자는 RC3에서 **실제 Chrome 탭 파비콘 색상 변경이 작동하지 않는다**고 보고했습니다. [원본 기록](favicon-user-report.md). 설정 상태, 실제 ChatGPT CSP 및 화면이 없어 원인은 확정하지 못했습니다. 기존 사이트 아이콘과 다수 링크 간 브라우저 선택, 사이트 CSP의 `img-src`, 파비콘 캐시, 사이트의 동적 링크 변경, 확장 재로드 후 남은 링크 등이 가능한 원인입니다.

## 변경 내용
- 기존 SVG `data:` 링크 대신 확장 내부의 32×32 PNG 아이콘을 사용합니다. `web_accessible_resources`로 해당 정적 아이콘만 `https://chatgpt.com/*`에서 접근할 수 있도록 허용합니다. 그 외 외부 네트워크는 사용하지 않습니다. 실제 ChatGPT CSP에서 이 확장 리소스를 허용한다는 보장은 없습니다.
- 사이트가 소유한 아이콘을 수정·삭제하지 않고 확장 링크만 추가합니다. 사이트가 새 아이콘을 삽입하면 확장 링크를 뒤로 이동합니다. 종료·설정 해제 시 확장 링크만 제거합니다. 이전 확장 세션에서 남긴 것으로 식별 가능한 전용 링크도 정리합니다. Chrome의 캐시나 아이콘 선택 정책에 따라 원본 복원 시각은 다를 수 있습니다. 확장 비활성화/제거 시에는 탭 새로고침이 필요합니다.
- 선택형 탭 제목 접두어: 작업 중 🔵, 완료 🟢, 오류/제한 🔴, 대기/중단/확인 불가 ⚪. 사이트가 제목을 바꾸면 새 제목을 보존하고 설정을 끄면 복원합니다. 확장에서 보낸 대화 제목에서는 접두어를 제거합니다. 제목 변경을 쓰는 다른 확장과 충돌할 가능성은 남습니다.
- 대시보드 **탭 표시 강제 시험**은 선택 탭에 4가지 상태를 약 15초 동안 적용하며 실제 작업 상태와 알림은 바꾸지 않습니다. 백그라운드 타이머 제한으로 복원이 지연될 수 있고 **시험 종료**로 바로 해제할 수 있습니다.
- 탭별 **진단**에는 링크 유무·우선순위, PNG 이미지 로드 검사, 감지된 CSP 위반 신호, Chrome `tabs.favIconUrl`과 요청 아이콘의 일치 여부를 표시합니다. CSP 이벤트가 발생하지 않을 수도 있고 이 메타데이터나 이미지 로드 성공은 실제 화면의 파비콘 표시를 증명하지 않습니다.

## 실제 실행 결과
- Node 단위/모의 Chrome API 테스트: **27/27 통과**, [로그](favicon-unit-test.log).
- Chromium headless shell의 **모의 DOM**에서 사이트 링크 추가 충돌, 원본 링크 및 사이트 제목 보존, 4개 강제 상태, 타이머 복원, 접두어가 메시지 제목에 섞이지 않는지 확인. 합성 `img-src 'self'`가 SVG data URL을 막는 사례와 합성 `img-src 'none'`이 data 이미지를 막는 사례를 재현. [로그](favicon-visual-mock.log). 이 결과는 실제 ChatGPT CSP, 확장 리소스 접근 또는 Chrome 탭 화면 테스트가 아닙니다.
- 기존 상태 감지 모의 DOM 회귀 통과: [로그](favicon-content-regression.log). 실제 ChatGPT에 대한 감지 정확도는 미검증입니다.
- 실제 확장을 로드하고 Chrome `tabs.favIconUrl` 변경·복원을 검사하도록 [E2E 스크립트](../tests/browser/extension-e2e.cjs)를 확장했습니다. 이 환경의 Chromium headless shell에서 실행했지만 확장 서비스 워커 등록을 확인하지 못해 **실패**했습니다. [로그](favicon-extension-attempt.log). 따라서 Chrome 탭 파비콘 갱신과 화면 표시 모두 **미검증**입니다. 확장 지원 Chromium 환경에서 `CHROME_PATH=경로 npm run test:extension`을 실행할 수 있습니다. 합성 페이지를 이용하므로 실제 ChatGPT 검증을 대체하지 않습니다.
- 설치 패키지의 소스·dist·ZIP 내부 19개 파일이 바이트 단위로 일치함을 확인했습니다. `release/gpt-task-manager-1.0.3.zip` SHA-256: `d49a2144080c2d815a339ddc9de0224ae85a0d658bd41fd9fb179aa89e9dc443`.

## Windows / 실제 Chrome 수동 확인
1. ZIP을 별도 폴더에 풀고 기존 압축해제 확장 폴더를 덮어씁니다. `chrome://extensions`에서 확장을 새로고침한 다음 **ChatGPT 탭도 새로고침**합니다. 기존 확장을 삭제하면 로컬 설정이 사라질 수 있습니다.
2. 대시보드의 알림 설정에서 **탭 파비콘 상태 표시**와 **탭 제목에 상태 표시**를 켭니다. 두 옵션은 기본적으로 꺼져 있습니다.
3. **탭 표시 강제 시험**을 열어 대상 탭을 선택하고 🔵 작업 중, 🟢 완료, 🔴 오류, ⚪ 확인 불가를 각각 시험합니다. 각 색상과 제목이 Chrome 탭에 실제로 나타나는지 눈으로 확인합니다. 이 시험은 자동 알림을 발생시키지 않습니다.
4. 시험 중인 탭의 **진단**을 눌러 링크 유무, 리소스 검사, CSP 차단 신호와 Chrome 아이콘 정보의 일치 여부를 기록합니다. 정보가 일치해도 실제 탭 표시를 별도로 확인합니다. 링크나 로드가 실패하거나 실제 아이콘이 바뀌지 않으면 제목 접두어를 대안으로 사용합니다.
5. **시험 종료** 후 파비콘 및 제목 옵션을 끄고 원래 사이트 아이콘과 최신 사이트 제목을 확인합니다. 원상 복귀가 지연되면 탭을 새로고침합니다. 다른 ChatGPT 탭과 사이트의 자체 아이콘·제목 업데이트에도 문제가 없는지 확인합니다.
6. 강제 시험과 별도로 실제 질문 제출·완료·중단·알림을 확인합니다. 실패 결과를 공유할 때 대화 제목, URL 및 본문이 노출되지 않게 주의하세요.

RC3의 상태 감지/완료 알림 및 새 파비콘 모두 실제 환경에서 추가 검증이 필요합니다. 출시 판정은 **NO-GO**입니다.
