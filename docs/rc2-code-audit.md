# RC2 시작 코드 감사 — 기준 25f3578

검토: manifest, content script, 상태 전이, service worker, 오프스크린 오디오, 대시보드, 테스트, 빌드. 기존 감사의 단계별 원장은 `audit.md`에 보존되어 있으며 독립 감사로 취급하지 않는다.

## P0 결함과 위험
1. 중지 버튼 부재 + 임의 assistant DOM 변경 + 4초만으로 완료 확정: 중간 응답/도구 호출 일시 정지를 완료로 잘못 판단 가능. 실제 최종 UI 근거 부족.
2. 사용자 제출 증거 없이 대기 후 Stop 버튼만으로 작업 시작: 외부/기존 상태 변경도 신규 작업으로 오인 가능. 재로드 중 작업 복원은 지원하지 않음.
3. 메인 프레임 및 sender.id 미검증; 비동기 content 메시지 응답 채널을 유지하지 않음. 동일 메시지도 저장 및 모든 탭 배지를 갱신하여 비용이 커짐.
4. ChatGPT의 탭 제목을 전송하려 했으나 정규식이 이중 이스케이프되어 접미어 제거가 실패함. 기존 프로젝트 이름은 탭을 닫으면 삭제됨.
5. 알림 실패가 소리 재생까지 차단할 수 있으며 알림 성공 여부/전달 보장 없음. 탭별 배지가 글로벌 미확인 수를 가림. 상태 저장과 알림 사이의 프로세스 종료 시 알림이 누락될 수 있음.
6. 상태 전이 6개 테스트는 DOM 관찰, Chrome API, E2E 및 실제 사이트 호환성을 검증하지 않음. 30개 탭 및 장시간 성능 미측정.
7. 파비콘·영구 프로젝트 설정·통계·백업·영어 등은 결함 수정 대상이 아니라 미구현 기능임. 보고서의 '완료'는 실제 서비스 검증 완료를 뜻하지 않음.

## 설치 패키지
ZIP과 dist는 이전 세션 생성물로 확인됨. 추후 최신 소스로 재빌드하고 파일 단위 해시를 비교한다. 현재 환경에 Chrome/Chromium은 PATH에 없음. 실제 서비스 및 Windows 알림은 미검증.

## RC2 변경 후
제출 근거 및 복수 신호 기반 후보 상태, 명시적 중단, 발신자 프레임·경로 검사, 비동기 응답 채널, 중복 상태 저장 억제, 프로젝트 경로별 저장, 선택형 파비콘/진단을 추가했다. 구현·검증 범위와 잔여 오탐/누락 위험은 `rc2-validation.md` 참조.
