# GPT Task Manager — 개발 중 (NO-GO)

ChatGPT 탭의 공개 화면 신호를 관찰하는 로컬 전용 Chrome MV3 확장입니다. **이 빌드는 실사용 RC1로 검증되지 않았습니다.** 실제 ChatGPT 화면과 Windows 알림에서 오탐·누락 가능성이 있으므로 중요한 작업의 완료 여부를 반드시 직접 확인하세요.

## 설치 (Windows 11 / Chrome)
1. 제공된 `release/gpt-task-manager.zip`을 압축 해제하거나, Node.js와 zip 유틸리티가 있는 환경에서 `npm run build`로 `dist`를 만듭니다.
2. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택하고 압축 해제한 폴더(또는 `dist`)를 지정합니다. 해당 폴더 바로 안에 `manifest.json`이 있어야 합니다.
4. 기존 ChatGPT 탭을 새로고침합니다. 확장 아이콘에서 팝업을 열고, Chrome의 사이드 패널 메뉴에서도 사용할 수 있습니다.
5. 설정의 알림 테스트를 실행합니다. Windows/Chrome 알림 권한 및 방해 금지 설정도 확인하세요.

## 사용 및 문제 해결
- 작업 중 `…`, 완료 `✓`, 오류 `!`, 감지 불가 `?` 등 확장 아이콘 배지와 대시보드를 확인합니다. 대시보드의 열기 버튼으로 탭에 이동합니다. 프로젝트 이름은 현재 탭에만 연결됩니다.
- 페이지 재접속·탭 중단 시 진행 중 작업은 복구하지 않고 불확실하게 처리합니다. 이미 진행 중인 응답을 열면 시작 이벤트가 관찰되지 않아 완료 알림이 없을 수 있습니다.
- 화면 구조 변화, 짧은 작업, 중간 도구 호출, 배경 탭 제한 등으로 누락 또는 오탐이 가능합니다. 새로고침하고 재시도해도 해결되지 않으면 이 확장에 의존하지 마세요.
- 알림 테스트가 작동하지 않으면 Chrome 및 Windows 알림 허용 여부와 방해 금지를 확인하세요. 소리 재생은 Chrome 오프스크린 문서와 시스템 오디오 설정에 의존합니다.

## 개인정보
ChatGPT 본문을 읽어 저장하거나 전송하지 않습니다. 제목, URL 경로의 대화 식별자, 프로젝트 이름, 상태 및 시각은 민감할 수 있으며 `chrome.storage.local`에 저장됩니다. 알림의 이름 숨기기 설정을 사용할 수 있습니다. 외부 서버, API, 추적, 쿠키, 인증 토큰, 네트워크 가로채기를 사용하지 않습니다. 프로젝트 이름 등 현재 탭 메타데이터는 탭을 닫으면 제거됩니다. 확장 프로그램 제거 시 로컬 데이터가 삭제됩니다.

## 개발
`npm test`는 Node 내장 테스트를 실행합니다. `npm run build`는 `dist/`와 `release/gpt-task-manager.zip`을 생성합니다. 자세한 범위와 미검증 사항은 [감사 보고서](docs/audit.md)를 보세요.
